2026-10-29 — Site-wide

Chart height no longer bounces with the text below it

The chart and the readout below it shared one fixed-height box, so a readout wrapping to one more line shrank the chart and dragged the text with it. The chart height is now fixed at 60 percent of the viewport height, capped at 480px, and the box grows only with the text.
