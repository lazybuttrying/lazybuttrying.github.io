최근 5거래일간 스프레드가 15bp 이상 벌어진 발행자. 시장이 해당 회사의 신용위험을 다시 가격하기 시작했다는 신호일 수 있음. (5일 이동중앙값 기준, 일 3건 이상 거래된 발행자만 집계)

최근 등급 변경

KOFIA 거래 데이터의 종목별 신용등급 변화를 종목 단위로 추적해 탐지. 등급은 평가사 발표 후 거래 데이터에 반영된 날짜 기준이며, 2거래일 이상 지속된 변화만 확정으로 표시.

스프레드 = 회사채 수익률 − 잔존기간 매칭 국채 수익률 (거래대금 가중평균). 동급대비 = 동일 신용등급 발행자들의 중간값 대비 괴리. 양수 = 동급보다 위험하게 거래됨.

스프레드 계산식
1. 개별 거래 스프레드(bp) = (채권 수익률 − 동일 잔존기간 버킷의 국고채 수익률 중간값) × 100
2. 잔존기간 버킷: 3M / 6M / 1Y / 2Y / 3Y / 5Y / 10Y / 20Y / 30Y (잔존기간은 YYMMDD 형식)
3. 발행자-일별 스프레드 = Σ(버킷별 중간 스프레드 × 버킷 거래대금) / Σ(버킷 거래대금) — 거래대금 가중평균
4. 일 3건 미만 거래된 발행자-일은 제외
5. 5거래일 이동중앙값으로 평활화
6. 동급대비(bp) = 자사 스프레드 − 동일 신용등급 발행자들의 당일 중간값
7. 5일변화 = 평활 스프레드 − 5거래일 전 값 / 20일변화 = 20거래일 전 값 대비
8. 단기 = 잔존기간 1년 이하 버킷만으로 3번 계산 / 장기 = 1년 초과 버킷만으로 계산
